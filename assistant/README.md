# 오늘의 비서

개인화된 아침 비서 웹앱. 빌드 없이 정적 파일로 동작합니다.

## 기능
- **날씨**: 현재 위치(또는 설정한 도시)의 현재·시간별 날씨, 미세먼지 — [Open-Meteo](https://open-meteo.com)
- **옷차림·준비물**: 체감온도 구간별 옷차림, 비·눈·미세먼지·자외선·일교차에 따른 준비물
- **계절 추천**: 오늘 날짜에 맞는 제철 활동·음식을 배경 장면으로 표시 (`data.js`의 `SEASONS`). 시즌마다 기간·절정·관심도를 두고 '다가오는 중 / 절정 / 끝물'로 점수를 매겨 가장 주요한 시즌을 고름. 배경을 누르면 시즌 목록에서 보기·숨기기·직접 추가/삭제. 전체 표는 `seasons.html`
- **관심 소식**: 관심사별 최근 7일 뉴스(GDELT 썸네일 + Google 뉴스), 유튜브 영상(API 키가 있으면 YouTube Data API, 없으면 Piped → 검색 링크), 인스타그램 해시태그 링크. 안 읽은 것·썸네일 있는 것 우선 3건 + 더보기(`#news`)
- **업무 영어**: 은행 프로덕트 UI/UX 디자이너용 표현을 하루 하나씩 (`PHRASES`)
- **지금 · 다음**: 홈 상단에 진행 중인 일정과 다음 일정. 누르면 전체 일정으로 이동
- **체크리스트**: '이번 달 꼭 할 일', '올해 목표'처럼 묶음(제목)별로 항목 관리
- **일정 타임라인**: 팝업으로 일정 추가·수정, 일정을 누르면 메모 작성과 Google 캘린더·iPhone(.ics)·Outlook 추가, 현재 시각 표시

설정(이름, 관심사, 지역)과 일정은 브라우저 localStorage에 저장됩니다.

## 한 파일로 묶기
```bash
python3 build.py   # dist/today.html — 이 파일 하나만 열어도 동작
```

## 실행
```bash
cd assistant && python3 -m http.server 8000
# http://localhost:8000
```
GitHub Pages로 배포하면 `/assistant/` 경로에서 바로 열립니다.
