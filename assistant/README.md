# 오늘의 비서

개인화된 아침 비서 웹앱. 빌드 없이 정적 파일로 동작합니다.

## 기능
- **날씨**: 누르면 일주일 날씨. 현재 위치(또는 설정한 도시)의 현재·시간별 날씨, 미세먼지 — [Open-Meteo](https://open-meteo.com)
- **옷차림·준비물**: 기온별 옷차림 룰(한여름~한겨울 8구간, 출퇴근 10시/20시 기온 기준). 퇴근길이 더 추우면 방한템, 낮이 많이 더우면 쿨링템 추가. 룰은 앱에서 편집 가능. 날씨에 따라 우산·마스크·모자·선글라스 등
- **계절 추천**: 오늘 날짜에 맞는 제철 활동·음식을 배경 장면으로 표시 (`data.js`의 `SEASONS`). 시즌마다 기간·절정·관심도를 두고 '다가오는 중 / 절정 / 끝물'로 점수를 매겨 가장 주요한 시즌을 고름. 배경을 누르면 시즌 목록에서 보기·숨기기·직접 추가/삭제. 전체 표는 `seasons.html`
- **관심 소식**: 오늘 올라온 기사 중 여러 매체가 함께 다룬(보도 규모가 큰) 순서로 3건, 나머지는 전체보기 팝업. 관심사별 뉴스(GDELT 썸네일 + Google 뉴스), 유튜브 영상(API 키가 있으면 YouTube Data API, 없으면 Piped → 검색 링크), 인스타그램 해시태그 링크. 안 읽은 것·썸네일 있는 것 우선 3건 + 더보기(`#news`)
- **업무 영어**: 은행 프로덕트 UI/UX 디자이너용 표현을 하루 하나씩 (`PHRASES`). '공부한 표현'에서 지금까지 본 표현을 검색
- **한 줄 메모**: 인사말 자리를 눌러 메모를 적으면 지울 때까지 유지, 없으면 시간대별 인사
- **지금 · 다음**: 계절 이미지 안에 진행 중인 일정과 다음 일정을 세로로. 누르면 전체 일정으로 이동
- **체크리스트**: '이번 달 꼭 할 일', '올해 목표'처럼 묶음(제목)별로 항목 관리, 묶음별 접기
- **일정**: 선택한 날의 타임라인(시간 없는 일정은 '종일'). 날짜 버튼을 누르면 다가오는 일정(날짜+키워드) 팝업, 누르면 그 날로 이동. 팝업 하단에서 빠른 추가 '1000피티-출근-1900피부과!'.
- **일정 상세**: 직접 추가·삭제하는 색상 카테고리, 중요 일정 빨간 표시, 팝업으로 일정 추가·수정, 일정을 누르면 메모 작성과 Google 캘린더·iPhone(.ics)·Outlook 추가, 현재 시각 표시

설정(이름, 관심사, 지역)과 일정은 브라우저 localStorage에 저장됩니다.

## 폰에 앱으로 설치하기
1. GitHub 저장소 **Settings → Pages**에서 *Deploy from a branch*, 브랜치와 `/(root)` 선택 후 저장
2. 1~2분 뒤 `https://luvson1986.github.io/luvson1986/assistant/` 접속
3. iPhone: Safari 공유 버튼 → **홈 화면에 추가** / Android: Chrome 메뉴 → **앱 설치**
4. 처음 열 때 위치 권한을 허용하면 현재 위치 날씨를 보여줘요

데이터(일정·체크리스트·메모·설정)는 폰 안에만 저장돼요. 설정 → **백업 파일 만들기**로 가끔 백업해 두세요.

## 한 파일로 묶기
```bash
python3 build.py   # dist/today.html — 이 파일 하나만 열어도 동작
```

## 실행
```bash
cd assistant && python3 -m http.server 8000
# http://localhost:8000
```
GitHub Pages로 배포하면 `/assistant/` 경로에서 바로 열립니다.
