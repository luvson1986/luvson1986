# 오늘의 비서

개인화된 아침 비서 웹앱. 빌드 없이 정적 파일로 동작합니다.

## 기능
- **날씨**: 현재 위치(또는 설정한 도시)의 현재·시간별 날씨, 미세먼지 — [Open-Meteo](https://open-meteo.com)
- **옷차림·준비물**: 체감온도 구간별 옷차림, 비·눈·미세먼지·자외선·일교차에 따른 준비물
- **계절 추천**: 오늘 날짜에 맞는 제철 활동·음식을 배경 장면으로 표시 (`data.js`의 `SEASONS`)
- **관심 뉴스**: 관심사별 최근 7일 Google 뉴스, 안 읽은 것 우선 3건 + 더보기(`#news`)
- **업무 영어**: 은행 프로덕트 UI/UX 디자이너용 표현을 하루 하나씩 (`PHRASES`)
- **일정 타임라인**: 날짜별 일정 입력·수정·삭제, 현재 시각 표시

설정(이름, 관심사, 지역)과 일정은 브라우저 localStorage에 저장됩니다.

## 실행
```bash
cd assistant && python3 -m http.server 8000
# http://localhost:8000
```
GitHub Pages로 배포하면 `/assistant/` 경로에서 바로 열립니다.
